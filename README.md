# 🌍 Air Pollution Analysis and Visualization

## 📌 Project Description
This project focuses on analyzing global air pollution data using Python.  
It includes data cleaning, exploratory data analysis (EDA), statistical analysis, and visualization to understand pollution patterns.

---

## 🎯 Objectives
- Analyze PM2.5, PM10, and NO2 pollution levels
- Identify trends over time
- Compare pollution across regions and countries
- Study relationship between population and pollution
- Categorize air quality levels

---

## 🛠️ Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## 📊 Dataset
- Source: World Health Organization (WHO)
- Ambient Air Quality Database (2024)

---

## 🔄 Process
1. Data Cleaning  
2. Data Transformation  
3. Exploratory Data Analysis (EDA)  
4. Statistical Analysis  
5. Visualization  
6. Insights Generation  

---

## 📈 Key Features
- Region-wise pollution analysis  
- Year-wise trend analysis  
- Correlation analysis  
- Population vs Pollution analysis  
- Air quality categorization
